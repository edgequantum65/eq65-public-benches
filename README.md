# Edge Quantum 65 — bancs publics

Laboratoire de recherche et développement à Lannemezan (Hautes-Pyrénées, France). Ce dépôt ne contient **ni code, ni données brutes, ni la recette** : il publie, pour chaque dossier, ce qui a été **mesuré**, ce qui **ne l'a pas été**, et les limites — y compris quand le résultat est défavorable.

Ces textes existent parce qu'un résultat de mesure n'a de valeur que s'il peut être contesté. Le protocole, les journaux bruts et le code sont fournis avec le dossier correspondant, sous accord de confidentialité.

## Ce que chaque dossier contient

Méthode décrite, code exécutable, tests, protocole écrit, journaux bruts rejouables, revue du statut du brevet source et des brevets tiers (sans avis de liberté d'exploitation), liste franche de ce qui reste à démontrer.

## Ce que ce dépôt n'est pas

- Ce n'est pas un avis juridique, ni une analyse de liberté d'exploitation.
- Ce n'est pas une preuve de performance industrielle : les mesures sont faites en simulation ou sur PC, jamais sur la cible du client.
- Ce n'est pas une offre de licence : les dossiers sont cédés, sur devis, à un seul acquéreur.
